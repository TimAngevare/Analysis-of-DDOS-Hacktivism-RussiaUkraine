## Analysis of DDOS attacks by hacktivists in the Russia-Ukraine war

This research is a project for the course Economics of Cybersecurity where through a dataset of news messages of DDOS attacks we want to find out what the marcro- and microeconomic impacts are of DDOS attacks by hacktivists.

  ## Research question

  > What economic impact do hacktivist DDoS attacks have on targeted organisations and on the
  > countries involved in the conflict (Russia and Ukraine)?

  Since the full-scale invasion on 24 February 2022, civilian volunteers and hacktivist collectives
  (for example the IT Army of Ukraine and pro-Russian groups) have taken part in the conflict
  through DDoS attacks. ENISA's analysis of 310 verified DoS incidents (Jan 2022 – Aug 2023) found
  that about 66% were politically or activist motivated and about 50% were related to the
  Russia–Ukraine war. Using reported incidents, we aim to:

  1. map who attacks whom,
  2. estimate disruption costs, and
  3. compare and rank hacktivist groups.

  ## Approach

  1. **Data collection.** A news dataset of DDoS-related stories, extended with recent events up to
     and including 2026.
  2. **LLM extraction** (`extraction.ipynb`). Local LLMs (via Ollama, run on the UTwente Jupyter
     cluster) turn each article into structured fields: attacker, victim, motive, cost, URLs/IPs
     and locations.
  3. **Graph analysis** (`analysis.ipynb`).
     - Parse the extracted JSON.
     - Normalise locations to countries.
     - Group stories into attack events by date and victim, because several stories can describe
       one attack.
     - Enrich victims with a sector from Wikidata.
     - Optionally load the result into Neo4j.
  4. **Economic modelling.**
     - *Microeconomic model:* the expected loss for one organisation, built from the likelihood of
       being attacked, the likelihood the attack succeeds, and the loss if it does. The inputs are
       0–1 scores such as how political the organisation is and its technical literacy.
     - *Macroeconomic model:* ranks hacktivist groups by the danger they pose, using external
       country data such as GDP, technical literacy and political favourability.
  5. **Interactive dashboard** (`docs/`) for exploring the results (*Note this is fully generated by AI*).

  ## Repository structure

  | Path | Description |
  |---|---|
  | `extraction.ipynb` | LLM-based entity extraction from news articles |
  | `analysis.ipynb` | JSON parsing, event clustering, Wikidata sector lookup, initial analysis |
  | `docs/` | Interactive dashboard (static site); see [`docs/README.md`](docs/README.md) |
  | `docs/build_dashboard.py` | Runs the notebook pipeline and writes `dashboard.json` |
  | `docs/actors.py` | Actor taxonomy: aliases, non-actors and side coding |
  | `neo4j/export_graph.py` | Exports the attack graph as CSV and Cypher for Neo4j |
  | `figs/` | Figures used in the report and presentation |
  | `parsed-ext-filtered.csv` | Filtered, LLM-parsed data for the extended period |
  | `wikidata_cache.json` | Cached Wikidata lookups, so reruns work offline |


  Dashboard

  The dashboard was generated with AI. It includes:

  - a map of victims, attackers and cross-border flows,
  - Russia and Ukraine compared sector by sector,
  - monthly attacks by side, against the 24 Feb 2022 line,
  - an actor ranking with profile cards,
  - a sortable browser of attack events, with links to the original reports.
